**A PC tool for changing the language of dialogue and text in Unity-based games.**

Unity Game Language Changer is designed for games with dialogue, story scripts, visual novels, gacha games, and other text-heavy games that lack localization or do not offer your preferred language.

Whether the game is installed through **Steam or another PC launcher**, you can simply select the game folder and change the language in supported games.

> **Note:** Compatibility depends on the Unity version, text system, and the specific implementation of the game. Support for every Unity game is not guaranteed.

## Features

* **Unity Games & Steam** — designed for games built with the Unity engine, including games distributed through Steam.
* **Dialogue & Story Text** — translates dialogue and story text in real time, replacing the original text directly in the game's text window.
* **Visual Novels** — designed for text-heavy games and visual novels, with real-time translation in seconds.
* **Gacha Games** — supports compatible Unity-based gacha games.
* **Games Without Localization** — intended for games that do not have an official translation or built-in language selection.
* **Simple Setup** — simply select the installation folder of the game.
* **Open Source** — the full source code is available for inspection, modification, and contribution.
* **Ready-to-Use `.exe`** — a precompiled executable is provided together with the source code.

## Supported Platforms

**Operating System:** Windows PC

* Steam

**Not supported:** Android, iOS, and game consoles.

## How to Use

1. Download the latest release or build the project from source.
2. Launch the application.
3. Select the installation folder of your Unity game.
4. Select the desired language and apply the change.
5. Launch the game and check the result.

Available languages and the exact behavior of the tool may vary depending on the game's implementation and compatibility.

## Anti-Cheat Warning

**The tool may not work with games protected by anti-cheat systems.**

Anti-cheat software may block external modifications or interfere with the tool's operation. Do not use the tool with protected multiplayer games or in situations where modifying the game may violate its rules.

Use the tool with compatible single-player games and visual novels where permitted.

## Limitations

* Not every Unity game is compatible with the tool.
* Some games use custom dialogue systems or encrypted resources.
* Certain languages may require fonts or text-rendering support that the game does not provide.
* Translating dialogue text does not necessarily translate textures, images, voice audio, or subtitles embedded in videos.
* Compatibility with Steam or another launcher does not guarantee compatibility with every game distributed through it.

## Open Source

The project includes the full source code and a ready-to-use executable.
